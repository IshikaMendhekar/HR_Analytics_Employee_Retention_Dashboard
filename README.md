# HR_Analytics_Employee_Retention_Dashboard
HR Analytics and Employee Retention Dashboard using Power BI
HR Analytics & Employee Retention Dashboard

Project Overview

This project focuses on analyzing employee data to understand employee retention and turnover patterns using Microsoft Power BI.

The dashboard helps HR professionals understand employee turnover across different departments, salary groups, and years of service.

Objectives

- Analyze total employee records.
- Understand employee retention and turnover.
- Compare employee turnover across salary categories.
- Analyze turnover based on employee tenure.
- Present HR data through interactive visualizations.

Dataset

Dataset Name: HR Analytics and Job Prediction

Source: Kaggle – Faisal Qureshi

Dataset Link: https://www.kaggle.com/datasets/mfaisalqureshi/hr-analytics-and-job-prediction

The dataset contains information about:

- Employee satisfaction level
- Last evaluation
- Number of projects
- Average monthly working hours
- Time spent in the company
- Work accidents
- Employee turnover status
- Salary category
- Department

Tools & Technologies

- Microsoft Power BI Desktop
- Kaggle Dataset
- Data Visualization
- Data Analysis

Dashboard Features

The dashboard includes four main visualizations:

1. Employee Count by Department – Shows employee distribution across departments.
2. Employee Retention & Turnover – Displays employees who stayed and employees who left.
3. Employee Turnover Rate by Salary – Compares turnover rates across salary categories.
4. Employee Turnover Rate by Tenure – Analyzes turnover based on years spent in the company.

Key Benefits

- Helps understand employee turnover patterns.
- Provides insights into employee retention.
- Supports HR decision-making.
- Makes employee data easier to understand through visualizations.

Conclusion

This project helped me understand how data visualization can be used in Human Resource Management. By using Power BI, employee information can be converted into meaningful insights that support better HR decisions.
